-change Apache and MySql configurations:

Goto "my.ini".
Simply add this under the mysqld tag skip-grant-tables.
Save the file, restart your server.

[mysqld]
max_allowed_packet = 512M

[mysqldump]
max_allowed_packet = 512M

innodb_buffer_pool_size = 50% of you RAM

----------------------------------------------------------------

Goto "php.ini".
Set upload_max_filesize=500M
Set post_max_size=500M
Set memory_limit= 25% OF your RAM (2000M)
Save the file, restart your server.

----------------------------------------------------------------

Enable Remote Access to phpMyAdmin:
1 -Edit the apache/conf/extra/httpd-xampp.conf file in your XAMPP installation directory (usually, C:\xampp).

2-Within this file, replace:

<Directory "/xampp/phpMyAdmin">
  AllowOverride AuthConfig
  Require local
  ...
with:

<Directory "/xampp/phpMyAdmin">
  AllowOverride AuthConfig
  Require all granted
  ...
3- restart the server

MySQL queries extremely slow in fresh XAMPP installation
added these to my.ini and restart the server:

#----------------------------------------------------
#          !!!! Query Cache Config !!!!
#----------------------------------------------------

query-cache-size = 524288000
query-cache-limit = 5242880
query-cache-type = 1

#----------------------------------------------------
#          !!!! InnoDB Buffer Config !!!!
#----------------------------------------------------

innodb-buffer-pool-size = 1000M
innodb-additional-mem-pool-size = 200M
innodb-log-files-in-group = 2
innodb-log-buffer-size = 10M
innodb-file-per-table = 1
